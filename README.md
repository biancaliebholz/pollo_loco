# El Pollo Loco

El Pollo Loco is a simple 2D jump-and-run game created as part of my frontend development training.

The project was built to practice object-oriented JavaScript and the implementation of basic game mechanics.

## Features

- 2D jump-and-run gameplay
- Character movement and jumping
- Enemies and collision detection
- Collectable items
- Sound effects
- Basic game logic and animations

## Technologies

- HTML
- CSS
- JavaScript

## About the Project

This project was created as a learning project during my developer training.
Its main purpose was to practice JavaScript, object-oriented programming, and basic game development concepts.
